# 看球 · Touchline Android

Android 9+ 足球信息 App，无需悬浮权限。

- 底部为赛程、资讯、数据、关注；顶部提供搜索与设置。关注页分为赛程球队、资料收藏、比赛订阅。
- 五大联赛、欧冠、美职联、中超及四项国内杯赛：打开先定位今天，上下滑动查看前两天完场与后续赛程，历史日期仍可查看更早比赛；日期筛选、轮次、比分、统计、事件、号码、评分与阵容站位。
- 关注支持 65 支欧洲、亚洲、美洲主要国家队，可搜索、排序、作为主队和筛选赛程；国家队队徽随安装包提供，支持桌面图标、开屏和小组件。补充国家及俱乐部中文名称、简称与别名，覆盖四项国内杯赛当前参赛队；杯赛队徽优先使用本地资源，缺失时显示「队徽暂缺」。
- 赛程提供「全部 / 俱乐部 / 国家队」标签，按类型单独查看。
- 国家队比赛开关默认开启并保存在本机：统一入口展示欧洲、亚洲、美洲主要成年男足国家队的世界杯、欧洲杯、亚洲杯、欧国联、预选赛和友谊赛，以及美洲杯、金杯赛、中北美及加勒比海国家联赛与美洲区世预赛，任一方为覆盖球队即可显示；关闭后不请求国家队赛程。新增欧联、欧协联和世俱杯。
- 比赛数据用主客队双色对比条展示，支持来源提供的全场/半场统计；逐分钟攻势图使用 FotMob 原始数据，缺失时明确提示，非进球概率。统计榜提供常用项目快捷入口。
- 球队和球员资料：阵容、近期战绩、历史交锋、伤停、转会、球员生涯及赛季表现；支持搜索和本地关注。
- 赛事资料：赛事横向切换，前置赛季入口在当前页展开选择，历史赛季、积分榜、球员/球队各项统计、完整赛程及杯赛晋级路线。积分榜默认显示手机核心列，可切换详细模式；球员资料分概览、技术统计和生涯。
- 中文资讯默认读取央视网足球文字报道，点击在 App 内阅读，提供返回、关闭及加载进度，不跳转外部浏览器；可切换懂球帝或 ESPN 英文资讯，支持翻页并记住来源。
- 4×2 主队桌面小组件：显示关注列表首位球队的近期比赛及比分；完场保留约 24 小时后切换下一场的日期和对阵，支持点击详情、手动刷新与明暗主题。在设置中添加，或长按桌面选择「看球」；约每 30 分钟后台更新，省电限制可能延后。完场计时优先记录赛中到完场的更新，首次读取的历史结果按开球后约两小时估算结束。
- 单场订阅与后台提醒默认关闭；启用并允许通知后，系统约每 15 分钟检查开赛、比分和完场，省电限制可能延后，不是秒级推送。通知可打开对应比赛。
- 赛程先显示本地缓存，按比赛状态更新；支持手动刷新、缓存用量和清理。数据缓存限 16 MB / 400 条，详情保留 2 小时、资料榜单 12 小时、资讯 1 小时、赛程最长 14 天；保留时长不等于刷新间隔。关注、订阅和外观不随清理删除，搜索词不保存。
- 关键事件可切换“只看进球”并记住选择。轮次独立缓存 14 天，每日检查变动，手动刷新可强制更新，随比赛数据缓存一起清理。
- 五种配色、日间/暗夜/跟随系统、主队桌面图标及检查更新。启动时以队徽配色描绘外轮廓与内部细节，下方显示主队名称，约 2.6 秒，完整彩色队徽停留后进入首页，可跳过；常用队徽从安装包读取。

比赛数据来自 ESPN、FotMob，中文资讯标题与图片来自央视网、懂球帝并链接原文，可能延迟、缺失或保留原文。伤停空白不代表全员健康，身价为来源估计，阵型站位不是实时坐标。资料关注与赛程球队关注分别保存；资料页可将支持的球队加入赛程关注。设置仅保存在本机，卸载会删除。

从 [Releases](https://github.com/AEGO-WRJ/touchline-mobile/releases) 下载 APK，可覆盖升级。

构建：Android Studio 打开仓库，或 JDK 17、Android SDK 35、Gradle 8.11.1 执行 `gradle :app:assembleDebug`。`web/` 是界面，`app/` 是安卓宿主，无 Node 依赖；WebView 需保持更新。发布签名仅存于 GitHub Secrets。
